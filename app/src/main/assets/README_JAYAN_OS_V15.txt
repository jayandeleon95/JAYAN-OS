JAYAN OS 1.5 — COMMAND & RECOVERY CORE
- Local voice command UI using available Web SpeechRecognition
- Voice commands for apps, Settings, notifications, Device Control, Lock, Focus, profiles, AOD
- Android RECORD_AUDIO permission scaffold
