JAYAN OS 1.1 — NATIVE NOTIFICATION BUILD
- Native Android NotificationListenerService source
- Native notification snapshot bridge to Jayan OS WebView
- Notification Center UI
- Up to two notification previews on futuristic Lock Screen
- Command palette shortcut for notifications
- Existing Native Core: installed apps, app launch, battery, camera, wallpaper/settings actions, flashlight
- Existing launcher UI/TLD/local data preserved

Android requirement:
After compiling/installing, Android notification access must be explicitly enabled by the device owner in system settings. Jayan OS cannot silently grant this permission.
