JAYAN OS 1.3 — DEVICE CONTROL
Adds:
- Device Control Hub
- Native Wi-Fi settings shortcut
- Native Bluetooth settings shortcut
- Per-window native brightness control
- Camera / flashlight / wallpaper / Android Settings controls in one panel
Preserves native apps/icons, notification badges, NotificationListenerService, lock-screen notifications, launcher HOME role, TLD and local settings.

Android note:
Modern Android deliberately restricts silent toggling of Wi-Fi/Bluetooth by ordinary apps. Jayan OS opens the appropriate system settings rather than bypassing Android security.
